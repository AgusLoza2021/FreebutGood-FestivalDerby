# Road surface art contract

Everything in this folder is generated by the road bake, except that **existing files are never
overwritten**. To bring your own art, drop a texture at the path below with the right settings and
run `Festival Derby / World / Build Road Surface Art` again: the builder keeps your texture and only
packages it into the array.

## Layers

The `Texture2DArray` slice index **is** the `SurfaceId` byte the bake writes into the road mesh's
vertex colour. That makes the order a wire format: changing it re-points every already-baked map at
the wrong albedo, so a change here requires re-baking every map.

| Slice | SurfaceId | File | Default look |
|---|---|---|---|
| 0 | `Street` | `Surfaces/Street.png` | dark asphalt |
| 1 | `Dirt` | `Surfaces/Dirt.png` | brown dirt |
| 2 | `Snow` | `Surfaces/Snow.png` | off-white snow |
| 3 | `Mud` | `Surfaces/Mud.png` | dark wet mud |
| 4 | `Gravel` | `Surfaces/Gravel.png` | grey gravel |

## Texture settings

| Property | Value | Why |
|---|---|---|
| Size | 128 × 128 (any square power of two, identical across all layers) | one array needs one size |
| Format | RGBA32, uncompressed | read back to build the array; the array is what ships |
| sRGB | on | albedo is colour, not data |
| Mip maps | on | the road is seen at a shallow angle |
| Wrap | Repeat | UV.u is arc length and runs to a large number around a loop |
| Filter | Bilinear | |

## Shader and material

- Shader `FestivalDerby/RoadSurface` (`RoadSurface.shader`): one forward pass, no Shader Graph, two
  `Texture2DArray` fetches per pixel, main-light lambert plus a flat ambient term. `#pragma target 3.5`
  because a texture array needs ES 3.0, which is the project's Android floor.
- Material `RoadSurface.mat` is written onto `MapAsset.RoadMaterial` by the bake, and the loader
  clones it at load time. The bake also sets `_Tiling` to `1 / RoadMeshSettings.MetersPerTile` so the
  art follows the UVs the sweep wrote.
- Vertex colour contract: **R = primary surface id, G = secondary surface id, B = blend weight**
  (`SurfaceBlend`), A unused. The shader decodes R/G by multiplying by 255.

## UV contract (written by `RoadMeshBuilder`)

- `u = arc length / MetersPerTile`; `v = lateral metres / MetersPerTile`, with `v = 0` on the left
  edge and `v = (WidthLeft + WidthRight) / MetersPerTile` on the right edge.
- Both axes share one physical scale, so a texture never stretches between a straight and a corner.
- UV continuity at the loop seam is positional, not arithmetical: the last ring is placed at
  `TotalLength` (a full tile count beyond the first), which is what makes a Repeat texture wrap with
  no visible seam. Do not integer-round `u` when editing the sweep.
